## Field Note

progeCAD Professional is easier to trust when the DWG workspace stays smaller than the folder it came from. A named session shows what is active, the file pins show what you will edit today, and the closing note tells the next person which source sheet changed.

The same loop fits a single detail, a client packet, or a PC shared by two people. Open the last progeCAD Professional drafting session, finish one edit, and leave fewer loose DWG copies than you found.

A review should not have to guess which source file belongs to the open workspace. Keep that pair together inside progeCAD Professional.

Other programs stay where they are. progeCAD Professional only holds the editor, the DWG workspace, and the handoff.

## One Real Pass

Pick a DWG set that already has a name. Open it in progeCAD Professional, keep only those source files on the workspace, and finish one edit you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different job and leave it out of this progeCAD Professional drafting session.
